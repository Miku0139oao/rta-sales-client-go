## 1. 安裝與開啟

1. 至 [Releases](https://github.com/Miku0139oao/rta-sales-client-go/releases) 下載 **`RTA-Excel-Filler-portable.exe`**，存入可寫入的本機資料夾。
2. 確認數位簽章有效；不要略過簽章無效警告。
3. 雙擊免安裝執行檔即可開啟 **RTA 銷售分析**。

同一時間只能開一個視窗。若按了沒反應，先看工作列是否已在執行。

若缺少 Runtime，請從 Microsoft 官方網站手動安裝 [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)。設定可檢查新版本、關閉啟動檢查。可信簽章的 Windows 免安裝版可明確確認「下載並重啟」；請先完成並匯出工作。v0.4.10 準備版雖可還原已快取的完成報表，但未完成工作與 Excel 分析／寫入結果不會還原，不要把快取當作備份。若顯示不支援原因，請關閉程式後以同路徑同檔名手動更新並保留舊版備份。

---

## 2. 第一次：加帳號

1. 左邊選 **帳號**。
2. 右上角 **新增帳號**。
3. 填寫：
   - **顯示名稱**：自己看得懂即可，例如「主要帳號」
   - **帳號**：RTA 登入帳號
   - **密碼**：RTA 登入密碼
4. 建議按 **測試並啟用**。程式會真的登入 RTA，確認帳密、驗證碼與門店權限。

未啟用的帳號不會用於銷售分析與 Excel 填入。

### 多本帳號

清單由上到下是優先順序。同一間門店若兩本帳號都能進，用較上面那本。用列上的上移／下移調整。

密碼放在 Windows 認證管理員，畫面與檔案都不會出現明文。

---

## 3. 商品代碼（選用，但做報告常會用）

左邊選 **商品代碼**。這裡建立的是 **promoter group**：一組 Item Code，之後可在分析頁只看這組商品，或在匯出時加群組摘要。

1. 新增一個群組，取名例如「維特健靈」。
2. 把該組要跟的貨號貼進去（可一次多個）。
3. 之後可匯出／匯入整個目錄，方便換電腦。

沒有群組也能做全店分析與匯出。

---

## 4. 開始銷售分析

1. 左邊選 **銷售分析**。
2. 選一本已啟用的帳號。
3. 勾要看的門店（可全選）。
4. 選擇分析期間：
   - **月份比較**（最常用）：選定一個月份
   - **日期範圍**：指定起、迄日期
   - **以星期比較**：指定起、迄日期，讓上期按相同星期對齊
5. 按 **開始分析**。

### 三種比較方式怎麼選

- **月份比較**：適合月報、檢視完整月份，以及同時比較上月、前期、去年同期與去年下月。
- **日期範圍**：適合促銷、活動或其他需要精確指定起迄日的情況；上期會以選取期間前一段相同天數的日期比較。
- **以星期比較**：適合週末或固定星期有明顯銷售差異的情況。上期會按相同星期對齊，讓週六、週日對照上期的週六、週日；適合避免週末與平日混在一起比較。

例如選取的 1–3 日為週末銷售日，以星期比較時，上期會對照相同星期的週末（週六、週日），而不是選取日期前緊接的平日。

### 月份比較會查哪幾段

| 名稱 | 意思 |
| --- | --- |
| 本期 | 你選的那個月 |
| 上期 | 上個月 |
| 前期 | 再上個月 |
| 去年同期 | 去年同一個月份 |
| 去年下月 | 去年的下一個月（用來準備接下來要補貨或主推） |

月份還沒過完時，前四段會算到「跟今天同一日」，比較才公平。例如今天 8 月 18 日，上期算到 7 月 18 日。去年下月仍是整月。

本期明細會先出來，其餘期間在背景補。進度列會顯示目前／全部。補完之前，**匯出 PDF** 可能還不能按。

## 5. 查完之後看什麼

上方有六個分頁：

| 分頁 | 看什麼 |
| --- | --- |
| 概覽 | 淨銷、銷售、退款、件數、交易、客單價、Top 商品 |
| 每週變化 | 本期各週、各店走勢 |
| 關注 | 去年下月賣得好的商品，方便準備下個月 |
| 分類 | 各分類在這幾期的差異 |
| 商品 | 明細列 |
| 門店 | 各店本期、上期、去年同期 |

**交易次數**與**客單價**是全店數字。一旦用分類或商品範圍縮小，這兩項會變成「全店數字時不適用」，因為來源沒有該細項的全店單。

---

## 6. 畫面上的篩選（會進報告）

篩選列由左到右：

1. **商品分類**
2. **商品部門**
3. **商品種類**
4. **四級類目**
5. **小分類**
6. **搜尋商品或編碼**
7. **商品範圍**（全部商品，或某一個 promoter group）

點開一層，勾要留的項目。可同時勾好幾層，條件是「而且」。

例如只看兩個小分類時：打開 **小分類**，勾那兩項。概覽數字、排行、商品表都會跟著變。

要清掉某一層：打開該層按 **清除**。

## 7. 匯出 PDF 與給 AI 的檔

畫面右上角是 **匯出 PDF**。點進去會開「匯出篩選」。

### 報告內容（最重要）

若你剛在畫面勾了分類或搜尋，這裡預設是 **依目前分析篩選**，並列出你勾了哪些項。

- **PDF** 與 **匯出給 AI 分析** 用**同一組條件**，不用再勾一次分類。
- 若要整店數字、不套用畫面篩選，改選 **不套用畫面篩選**。
- 「忽略沒有金額的贈品」「忽略印花」預設開啟，一般維持即可。

若畫面沒有篩選，這裡仍可用「排除／只保留下列分類」做進階挑選。

### 匯出格式

- **PDF 報告**：給人開會看的正式報告。
- **匯出給 AI 分析**：Markdown，丟進任何 AI 就會出報告，不用再打提問。

可兩個都勾。AI 檔開頭已寫好任務與規則：只能用檔裡的數字、不准發明商品或金額、幣別是港幣；沒出現的分類不要當成銷售為 0。檔裡含本期、上期、前期、去年同期、去年下月（有資料才列出）。

### 多間門店

可出一份 **總報告**，以及勾選的 **分店報告**。

### 群組報告（有建立商品代碼時才會出現）

- **只顯示總結在總報告**：總 PDF 只加各群組一頁摘要，避免頁數暴增。
- **詳細（獨立匯出 PDF）**：每個勾選的群組另出一份完整 PDF。

沒勾任何群組就只出全店報告，這是正常的。

選一個資料夾後開始匯出。檔名重複會自動加數字，**不會覆蓋舊檔**。完成後可按 **開啟資料夾**。

## 8. 把數字填進 Excel

左邊選 **Excel 填入**。程式只寫兩個欄位，而且 **一定另存新檔，原本的 Excel 不會被改**。

公司檔預設工作表名稱為 `Dairly`（此拼法為原檔既有寫法）：

| 欄 | 內容 |
| --- | --- |
| C | 門店編號 |
| F | 日期 |
| L | 當天銷售金額（銷售減退貨） |
| AB | 當天交易次數 |

### 三步

1. **選擇範圍**：開啟 `.xlsx`（不支援舊的 `.xls`），選工作表與起迄日，核對掃描摘要後按 **開始分析**。
2. **檢查結果**：將變更／不變／問題列。
3. **另存並寫入**：指定新檔位置。可用「開啟檔案」或「在資料夾中顯示」。

來源檔有不同數字時，須先開 **允許覆寫全部不同值**，否則會列為問題列。儲存格若是**公式**，程式不會改。查詢失敗可按 **重試失敗項目**。

C 欄若不是 RTA 門店編號，到 **設定** 指定本機對照檔。

## 9. v0.4.10 準備中／尚未發布：新行為

以下依準備版實作說明；既有圖／影片仍是舊版，不是新版驗證紀錄。[v0.4.10 改版資訊（準備中／尚未發布）](releases/v0.4.10.zh-TW.md)。

### 分類占比與匯出

- 占比 = 該分類淨銷售額 ÷ **同期間篩選後各分類淨銷售額總和**。本期、上期、前期與去年同期各用自己的分母；不是未篩選的全店占比，也不是只加總畫面顯示的 Top N。
- 例如同一期篩選後兩分類淨銷為 80 與 20，占比分別為 80% 與 20%；若再縮小篩選，分母也會改變。有效負淨銷不會強制歸零。
- 期間尚未完成、缺少期間／數值或分母為零時，占比留白，不填 0%；PDF 缺值位置以 `-` 表示。
- 分類比較畫面與 PDF 的分類表現區塊把占比放在對應金額下方。PDF 依匯出時實際套用的篩選計算，改成「不套用畫面篩選」後，分母可能與畫面不同。
- 分析表格的 **匯出 Excel／複製 TSV** 將金額與占比分成獨立欄位：Excel 保存數值比例並套用百分比格式；TSV 獨立欄輸出百分比文字。缺值在 Excel／TSV 留白，不會把金額與百分比塞在同一格。這不是第 8 節的每日「Excel 填入」。

### 切換頁面與重啟是兩回事

| 動作 | 準備版行為 |
| --- | --- |
| 同一次開啟期間切換頁面再返回 | 保留頁面狀態，包括分析、Excel 預覽／寫入完成狀態及設定草稿；工作執行中仍可能限制切頁 |
| 桌面重啟後載入銷售分析 | 有可用快取時還原上次完成報表，提示保存時間；這是當時查詢結果，不是最新 RTA 資料，請重新分析以更新 |
| 桌面重啟後進入 Excel 填入 | 只還原上次活頁簿路徑與工作表，檔案仍存在時重新掃描；不保存或還原重啟前的分析預覽／寫入結果，需重新分析並確認後再寫入 |
| 修改查詢工作／本機對照設定 | 設定頁與導覽標示「有尚未儲存的變更」；切頁會保留草稿，仍須按「儲存」才套用；主題／語言維持立即生效 |

桌面完成報表會在背景**非同步**保存為 `sales-report.json.gz`；未完成報表不保存。這是 **gzip 壓縮 JSON，沒有加密**，不是 Windows 認證管理員保護的密碼資料。快取寫入失敗、損毀或不相容時可能無法還原，重要報表請自行匯出。上述磁碟還原機制限桌面版，不代表網頁版也會跨重啟保存。

`workbook-session.json` 只記錄活頁簿路徑、工作表及保存資訊，不保存活頁簿內容、分析預覽或寫入結果。檔案搬移／刪除或掃描失敗時，請重新選檔。已另存的 Excel 檔仍是獨立檔案，不因程式不還原成功畫面而被刪除。

### 本機資料與清除順序

桌面資料夾沿用舊產品名稱：`C:\Users\你的使用者名稱\AppData\Roaming\RTA Excel Filler`。其中包含帳號資料、加密登入狀態，以及準備版未加密的報表快取和活頁簿路徑資訊，請勿隨意分享。

要清除時，請依序：

1. **先在程式「帳號」頁刪除全部帳號**，移除對應認證與登入狀態。**刪帳號不會刪除已保存報表。**
2. **完全關閉程式**，避免背景快取寫入又建立資料。
3. **再刪除上述資料夾**，清除其中的報表快取與活頁簿紀錄等資料。

另外匯出的報告、來源活頁簿與另存的 Excel 副本不會隨此資料夾一起清除，如需移除請另行處理。

## 10. 常見狀況

| 情況 | 怎麼辦 |
| --- | --- |
| 開了沒視窗 | 看工作列；同時只能開一個 |
| 測試帳號一直驗證碼錯 | 隔一分鐘再試；並用瀏覽器確認帳號能登入 RTA |
| 分析沒有門店 | 帳號要已啟用且最近一次測試成功 |
| 匯出按鈕按不了 | 等本期明細載完、其餘期間補完（進度列走完） |
| 報告數字跟畫面不一樣 | 匯出時是否改成「不套用畫面篩選」；或畫面篩選後來又改了，請重開匯出對話框 |
| Excel 很多「找不到門市對照」 | C 欄編號與 RTA 不一致，核對來源檔或設定對照 |

## 11. 0.4.4 相較更舊版本的差異

- 舊教學按匯出後，報告是全店分類條件，**不會**自動帶你在概覽勾的小分類。
- 現在預設 **依目前分析篩選**，PDF 與 AI 同一套。
- 群組詳細內容改為可選的獨立 PDF，不再全部塞進總報告。
- 給 AI 的檔已含任務與規則，直接丟進去就會出報告，不要只丟原始數字。

# v0.4.13：一般資料夾原地更新

- 不再因磁碟根目錄或一般資料夾的擁有者不同、繼承其他本機帳號的修改權限，就拒絕免安裝版更新。可保留原本的本機下載資料夾與檔名。
- 不會修改磁碟、資料夾或既有執行檔的權限；仍須有實際建立暫存與替換檔案的權限。
- 保留私有暫存、正式版本與同發行者簽章、下載雜湊、檔案身分、禁止寫入／刪除的檔案鎖、備份與回復驗證。
- 更新檔／回復檔移入原位置後，仍驗證其受保護權限，再以核對過的執行檔重啟。

安全界線：信任對安裝資料夾有修改權限的本機帳號；不再宣稱防止這些帳號惡意變更上層路徑。連結／重解析路徑、硬連結執行檔、未受信任簽章及遭變更的更新檔仍會拒絕。

v0.4.12 或更舊版若已被路徑條件擋住，請先關閉程式，手動替換為本版本一次，保留原檔名及舊版備份；後續可在原路徑使用自動更新。

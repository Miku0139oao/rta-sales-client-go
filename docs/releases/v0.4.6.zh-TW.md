# RTA 銷售分析 0.4.6

**新增以 GitHub Releases 為來源的程式內更新。** 不需要另外架設更新伺服器；今後版本、改版資訊與下載檔都由這個 GitHub 專案提供。

## 下載與首次升級

本版只提供 **Windows 10／11 64 位元免安裝版**，使用 Microsoft Trusted Signing 簽署，不再產生新的安裝檔。歷史 Release 的安裝檔仍保留。

| 檔案 | 用途 |
| --- | --- |
| `RTA-Excel-Filler-portable.exe` | **請下載這個檔案**，免安裝，直接執行。 |
| `SHA256SUMS.txt` | 已簽署執行檔的 SHA-256 校驗碼。 |
| `RTA-Sales-Analyzer-v0.4.6-screenshots.zip` | 更新確認與重啟後設定保留的隔離驗證截圖。 |

**v0.4.5 或更舊版本沒有更新功能，需要先手動下載本版。**

1. 先完成查詢、匯出報表並關閉舊程式。
2. 保留舊執行檔備份，再將新版放回**相同資料夾、相同檔名**；原本若叫 `RTA-Excel-Filler.exe`，新版也請使用該名稱。
3. 開啟新版，在「設定」使用「檢查更新」。未來有新正式版時即可透過程式內更新。

帳號與設定不需要重新建立。為保留 WebView 設定，請不要任意改變既有執行檔名稱。不要先解除安裝舊版而刪除使用者資料；若原目錄沒有寫入權限，請依管理員指示遷移，勿強制覆蓋。

缺少 WebView2 Runtime 的電腦請先安裝 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)；免安裝檔不會代為安裝 Runtime。

## 更新功能

- **GitHub Releases 作為唯一版本來源**：只查詢此專案最新正式版本，不採用草稿或預發行版。
- **顯示目前版本與改版資訊**：可在設定手動檢查；啟動時的背景檢查預設開啟，也可關閉。
- **不自動下載或強制更新**：必須按「下載並重啟」，閱讀提醒並確認，才會下載。檢查更新只讀取版本資訊。
- **下載後多重驗證**：校驗 SHA-256、Windows 信任簽章、發行者、執行檔架構與版本；任何驗證失敗都不執行更新檔，也不提供略過驗證的選項。
- **安全替換與備份**：更新助手等待原程式正常退出後，替換原路徑的執行檔並重新啟動；保留舊檔及診斷紀錄，替換或啟動失敗時嘗試還原。
- **保護正在進行的工作**：查詢、背景明細、帳號操作、Excel／PDF／AI 匯出期間拒絕更新；更新開始後也不接受新工作。
- **取消與錯誤提示**：下載／準備階段可以取消；助手已確認接手、進入關閉重啟階段後不可取消。

## 使用限制

- 重啟會失去**未儲存的報表與預覽**，請先完成並匯出工作。
- 更新僅支援可信簽署的 Windows 64 位元正式版。開發版、未簽署版及網頁版不提供執行檔自動更新。
- 共用或權限不安全的資料夾、遠端路徑、重新解析點等位置可能被拒絕；請使用自己有寫入權限的安全本機資料夾。
- GitHub 離線／限流、Windows 簽章或撤銷資訊無法驗證時會提示錯誤，保留目前版本；不需要填寫 GitHub Token。
- 備份保留不代表斷電時可完全自動回復。若更新中斷且原執行檔不見，可從相鄰 `.rta-update-*` 目錄保留的 `previous.exe` 手動回復；不要刪除唯一可用的備份。

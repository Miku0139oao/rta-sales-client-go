# RTA 銷售分析 0.4.5

這次更新讓銷售分析從「看排行」延伸到「追查商品、核對變動、帶走完整表格」，並修正日期比較、取消查詢及報告資料一致性問題。

## 下載與安裝

本次提供 **Windows 10／11 64 位元**正式版；安裝版與免安裝版皆以 **Microsoft Trusted Signing** 簽署。

| 檔案 | 用途 |
| --- | --- |
| `RTA-Excel-Filler-setup.exe` | **一般使用者請下載這個檔案**，安裝後從開始功能表開啟「RTA 銷售分析」。 |
| `RTA-Excel-Filler-portable.exe` | 免安裝版；需要 Microsoft Edge WebView2 Runtime。 |
| `SHA256SUMS.txt` | 核對兩個執行檔的 SHA-256 完整性。 |
| `RTA-Sales-Analyzer-v0.4.5-screenshots.zip` | 本版四張功能截圖與畫面說明，皆為合成示範資料。 |

本次未附新版 Linux／macOS 執行檔。檔名沿用 `RTA-Excel-Filler`，程式名稱仍為「RTA 銷售分析」。

## 新增與改進

### 分析更容易追查

- **點商品就能看詳情**：在排行、分類、關注或商品表格點商品名稱，查看同一編碼的跨期間銷售、數量、退貨及各門店明細。不會另外發起新的 RTA 銷售查詢。
- **表格可排序**：商品、分類、門店、每週變化與商品詳情均可點欄名切換排序；商品表格每頁 50 筆。
- **看懂營收變動來源**：「分析重點」可展開計算依據，分別按門店與最上層分類拆解淨銷售差額。兩種拆解各自對帳，不能相加，也不代表因果；期間或門店資料不完整時不提供誤導的比較。
- **常用條件與捷徑**：可儲存常用查詢／篩選、釘選最多 3 組，並顯示最近成功使用的條件。套用只會帶入草稿，仍須按「開始分析／重新分析」才查詢。
- **操作更順手**：啟動先開銷售分析，查詢期間仍可切換頁面；調整條件時保留既有報表脈絡。桌面首屏更精簡，窄螢幕與深色模式同步改善。

### Excel、PDF 與 AI 報告更完整

- **匯出此頁 Excel**：依當下頁籤、篩選、排序及排行深度產生 XLSX；商品表格包含所有分頁，不只眼前 50 筆。商品詳情亦可單獨匯出。
- **一鍵複製表格**：可貼入 Excel；剪貼簿受限時提供手動複製方式。
- **保留可核對資料**：金額維持數值型別、商品編碼保留前導零，文字不會被當成公式；桌面版同名檔自動加序號，不覆蓋舊檔。
- **完整差額證據**：概覽 Excel 附分析重點、門店差額拆解與分類差額拆解，包含未列入畫面預覽的群組。
- **PDF 長排行修正**：按實際卡片容量分頁，修正長排行續頁，並明示資料不完整的情況。
- **AI 報告說明修正**：排行筆數說明依實際設定產生，不再把所有報告寫成同一個固定深度。

### 正確性、穩定性與效能

- 修正「以星期比較」的每週比較範圍，以及只查部分門店時的趨勢總額；較長期間的 Trend 查詢拆成最多 90 天的區段。
- 隔離各次查詢工作階段並保存不可變報表快照，避免舊查詢、切換帳號或後續明細影響目前報表。
- 取消分析後清除待處理狀態；取消登入後不再重試驗證碼。
- 帳號清單載入失敗不再被誤認為尚未建立帳號；覆蓋商品代碼清單前先確認。
- 改善網頁版 Cookie 失效處理及查詢事件連線保活；每帳號可設定的額外 RTA 登入上限由 4 提高至 8。
- 精簡大量商品列解碼，移除逐列中介物件。本機合成資料測試有改善，但不代表真實 RTA 伺服器或整體查詢一定等比例加速。

## 升級注意事項

- 升級前請先關閉舊版；既有帳號、設定與商品代碼無須重新建立。建議先匯出重要設定備份。
- 商品詳情使用報表內同一商品編碼的完整門店／期間範圍，不套用主畫面的分類或商品群組篩選。
- 每週數據維持全店範圍，不套用商品篩選；Excel 說明頁會標記範圍。
- Excel 單次匯出上限為 50 萬個資料儲存格；超出時請縮小篩選。
- 一般排行提供 16／24／32 與自訂 5–100；「關注」維持畫面 10 筆、PDF／AI 8 筆的既定差異。
- 舊版 0.4.4 教學影片仍可參考基本操作，但不涵蓋本版新增工具，未作為新版影片重新上傳。

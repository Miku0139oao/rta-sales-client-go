# RTA 銷售分析 0.4.8

**修正全螢幕設定頁錯位，並新增直接讀取 GitHub Release 的更新日誌。** 已是最新版也能查看改版內容，不需要額外伺服器。

## 下載與更新

- **v0.4.6／v0.4.7 使用者**：在「設定 → 檢查更新」確認下載並重啟；請先匯出未儲存的報表。
- **v0.4.5 或更舊版本**：先手動下載、關閉舊程式並保留備份，再以相同路徑與檔名替換。
- 本版只提供 **Windows 10／11 64 位元免安裝版**，以 Microsoft Trusted Signing 簽署。缺少 Runtime 時請手動安裝 [Microsoft Edge WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)。

| 附件 | 用途 |
| --- | --- |
| `RTA-Excel-Filler-portable.exe` | 已簽署的免安裝正式版。 |
| `SHA256SUMS.txt` | 執行檔 SHA-256 校驗碼。 |
| `RTA-Sales-Analyzer-v0.4.8-screenshots.zip` | 全螢幕、更新日誌與窄畫面驗證截圖。 |

## 本版改進

- **全螢幕不再左右錯位**：更新卡片與設定內容共用置中、同寬的欄位，修正大螢幕時上方靠左、下方置中的問題。
- **新增「更新日誌 / Changelog」**：直接讀取此專案 GitHub 最新正式 Release 的改版資訊，標明內容對應版本。
- **最新版也能查看**：日誌與可安裝更新分開處理；沒有較新版本時仍顯示最新正式 Release 的日誌，不會因此產生重複更新或降版按鈕。
- **可收合與捲動**：長內容不會無限制撐高頁面；內容以安全跳脫文字呈現，不執行 Release 中的 HTML。
- **既有安全流程不變**：檢查只取得版本資訊，下載仍需明確確認；SHA-256、簽章與發行者驗證、備份還原及工作互斥保持不變。

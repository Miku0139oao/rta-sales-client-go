# v0.4.14：查詢工作區與本機報表流程

- 跨頁顯示查詢階段、進度與失敗原因，可返回分析頁或取消查詢。保留切换頁面時正在執行的工作。
- 查詢部分失敗時，可只重試失敗的門店／期間與交易趨勢；保留成功資料，並重新驗證帳號與門店權限。重啟後若重試上下文已失效，請重新查詢。
- 報表摘要列顯示期間、門店範圍、完整性、資料時間與查詢耗時。
- 常用條件可儲存 PDF、Excel、AI 摘要及各門店匯出選項，一鍵查詢並等待資料補齊後產生 ZIP 報表包。查詢不完整時停止匯出。桌面版只選一次資料夾且不覆寫既有檔案；網頁版完成後按下載 ZIP。報表包原始資料上限 190 MiB。
- 表格提供搜尋、排序、欄位顯示設定、固定表頭及返回時的閱讀位置；大型非分頁表格只渲染可見列。Excel／複製保留完整欄位與搜尋後的所有列。
- 歷史報表摘要可儲存、比較、匯出 JSON 備份及確認後刪除。桌面版存於使用者資料目錄，網頁版存於 IndexedDB；不新增雲端報表資料庫。上限 20 份，達上限不自動刪除。
- 只比較完整且帳號、門店、商品篩選範圍一致的摘要。差額為 A 減 B，變化比例以 B 絕對值為基準；B 為零時不顯示比例。歷史記錄不包含完整商品明細，也不在裝置間同步。

上游 RTA 回應時間仍影響首次查詢耗時。本版減少失敗後的重複查詢，改善操作回饋與大型表格的畫面負擔，不宣稱固定的首次查詢速度。

驗證：前端型別檢查／測試／正式建置、Go 全套測試與 vet、Linux desktop race 測試；以合成資料確認歷史儲存及 320／390 像素視窗操作。未以真實帳號額外查詢或外傳銷售資料。

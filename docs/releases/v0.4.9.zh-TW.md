# RTA 銷售分析 0.4.9

**版本檢查改由 GitHub Pages 提供，不再消耗 GitHub 未登入 API 額度。** 改版資訊仍來自 GitHub Releases，執行檔仍從 Release 附件下載；不需要額外伺服器、登入或 GitHub Token。

## 首次切換請手動更新

**v0.4.8 及更舊版本仍使用舊 API 來源。若遇到 403／限流，請直接下載本版，不必反覆按檢查更新。**

1. 完成查詢並匯出未儲存的報表，關閉舊程式。
2. 保留舊執行檔備份，將本版放回**相同路徑、相同檔名**，以保留既有 WebView 設定。
3. 開啟 v0.4.9，之後可在「設定 → 檢查更新」使用新的 Pages 來源。

| 附件 | 用途 |
| --- | --- |
| `RTA-Excel-Filler-portable.exe` | **請下載此檔**：已透過 Microsoft Trusted Signing 簽署的 Windows 10／11 64 位元免安裝版。 |
| `SHA256SUMS.txt` | 已簽署執行檔的 SHA-256 校驗碼。 |

缺少 Runtime 時請先安裝 [Microsoft Edge WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)。本版不新增安裝包，歷史 Release 不變。

## 本版改進

- **靜態 Pages 版本清單**：程式只讀取固定的 [`updates/latest.json`](https://miku0139oao.github.io/rta-sales-client-go/updates/latest.json)，不再呼叫 GitHub Releases API，也不會回退到該 API。
- **正式發佈後自動同步**：GitHub Actions 使用自己的授權查詢最新正式 Release，核對附件雜湊、簽章、發行者及版本後，才更新 Pages。草稿與預發行版不作為更新來源。
- **原有網站保留**：版本清單與既有文件／架構圖一起部署，不另建伺服器；文件更新也會重新產生版本清單，避免清單被覆蓋遺失。
- **快取減少重複請求**：啟動檢查重用一小時內的有效公開版本資料；快取讀取時仍重新驗證版本與附件資料。手動檢查會重新取得資訊，不受本機快取時間限制。
- **失敗時不反覆重試**：背景檢查失敗後採用逐步延長的重試間隔，最多一小時；服務端要求的 `Retry-After` 也會遵守，並提示何時再檢查。不使用不斷重試的計時器。
- **不保存帳號憑證**：快取只有公開改版資訊與檢查時間，不包含 GitHub Token、RTA 密碼或 Cookie；快取無法寫入時退回記憶體快取，不妨礙手動檢查。
- **下載安全維持不變**：仍需明確確認才下載，並驗證清單附件摘要、SHA256SUMS、Windows 簽章、發行者及執行檔版本，再由助手備份、替換及重啟。

## 注意事項與驗證

Pages／CDN 在發佈後可能需要一段時間更新；Pages 不是離線服務，也不能保證任何網路永遠不會限流。新版移除的是 GitHub 匿名 API 每個出口 IP 每小時 60 次的限制，不是繞過服務端安全限制。

本版前端 314 項測試通過，Go 測試、靜態檢查、更新相關 race 測試及安全複審通過。清單產生器另測試 37 個合成拒絕案例，並以真實已公開 Release 完成簽章、發行者、數值版本、附件摘要與校驗碼驗證。此輪不改版面；全螢幕與更新日誌畫面可參考 [v0.4.8 截圖](https://github.com/Miku0139oao/rta-sales-client-go/blob/v0.4.8/docs/releases/v0.4.8.zh-TW.md)。

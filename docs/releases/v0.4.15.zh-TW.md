# v0.4.15：手機操作與完整本機報表

- 手機查詢按鈕不再遮住門店選項，底部導覽保留自己的空間；六個報表分頁可直接看見及點選。
- 手機明細預設卡片，商品先顯示淨銷售額、數量與門店，可展開其餘欄位、搜尋、排序及翻頁，亦可切回完整表格。Excel／複製仍保留完整欄位與全部篩選後的列。
- 網頁自動儲存最近一份完整報表及所有期間明細，重新開頁從本機恢復原帳號與查詢範圍。小型報表存 localStorage，大型報表或容量不足時改存 IndexedDB；不增加伺服器報表資料庫、不跨裝置同步。
- 已保存報表的商品明細與 PDF 資料組裝不依賴服務端工作階段。畫面標示本機儲存時間，可更新資料或確認後清除完整本機報表，帳號／常用條件／歷史摘要保留。
- 未完成、失敗或明細不齊的查詢不覆蓋上一份成功保存的報表。儲存失敗會明確提示。
- 修正首次工作階段與事件連線的建立順序。結果已過期時顯示單一中文提示與重新查詢入口，保留已載入資料，停止五個期間重複報錯。
- 更新資料與隱私說明，清楚區分伺服器暫存與本機保存。服務端閒置兩小時清理維持不變。

舊版只保存摘要的報表，若服務端明細已過期，需要重新查詢一次；完成後本版會自動保存完整明細。清除瀏覽器網站資料或無痕模式仍可能使本機報表消失。網站資產載入與 Excel 活頁簿組裝仍需網站連線。

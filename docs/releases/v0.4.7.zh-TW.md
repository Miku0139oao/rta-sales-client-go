# RTA 銷售分析 0.4.7

**更新介面重新整理，與現有 Wails 3 桌面程式的設定頁風格一致。** 本版專注外觀與操作呈現，不改動更新下載、簽章驗證或備份還原邏輯。

## 下載與更新

- **已使用 v0.4.6**：開啟「設定 → 檢查更新」，確認後下載並重啟。請先匯出未儲存的報表。
- **v0.4.5 或更舊版本**：手動下載本版，先關閉舊程式並備份，再以相同路徑、相同檔名替換，保留既有設定。
- 本版只有 **Windows 10／11 64 位元免安裝版**，以 Microsoft Trusted Signing 簽署。若電腦缺少 WebView2，請安裝 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

| 附件 | 用途 |
| --- | --- |
| `RTA-Excel-Filler-portable.exe` | 免安裝正式版；一般使用請下載此檔。 |
| `SHA256SUMS.txt` | 已簽署執行檔的 SHA-256 校驗碼。 |
| `RTA-Sales-Analyzer-v0.4.7-screenshots.zip` | 本版介面的淺色、深色確認視窗及窄畫面截圖。 |

## 本版改進

- **更新區塊融入設定頁**：沿用現有卡片、圖示、字級、間距及色彩，移除突兀的瀏覽器預設按鈕與勾選框外觀。
- **版本與狀態更清楚**：目前版本以標籤顯示，檢查中、已有新版、無新版及錯誤各有清楚提示。
- **統一操作元件**：檢查更新、下載重啟及取消改為一致的主／次要按鈕；啟動檢查使用開關，並說明不會自動下載。
- **改版資訊可收合**：長內容限制高度並可捲動，不再撐滿設定頁；仍以跳脫文字顯示，不執行遠端 HTML。
- **重新設計確認視窗**：顯示舊版 → 新版對照，明確警告未儲存資料會遺失，並說明已儲存帳號與設定會保留。
- **淺色、深色與窄畫面一致**：調整按鈕排列、焦點樣式、對比及間距；其他頁面的更新通知保持精簡。

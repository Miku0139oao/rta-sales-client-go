# RTA 銷售分析 0.4.10（發布準備中）

**本頁是尚未發布的改版草稿，不代表已提供 v0.4.10 下載或完成簽章驗證。** 正式附件與更新資訊以 [Releases](https://github.com/Miku0139oao/rta-sales-client-go/releases) 為準。

## 本版改進

- **分類占比**：本期、上期、前期及去年同期的分類金額可搭配占比閱讀。分母是同期間套用篩選後的分類淨銷總額，不是未篩選的全店銷售額；期間未完成、資料缺少或分母為零時不提供有效百分比。占比不是增長率，不使用增減箭頭或漲跌色。
- **維持比較表寬度**：畫面與 PDF 將占比放在金額下方；Excel 與 TSV 保留獨立占比欄；Excel 保存數值比例以便運算，TSV 輸出百分比文字。分類排行另顯示金額與件數占比。
- **切頁保留工作**：已開啟的分析、Excel 與設定頁保留狀態；返回帳號與商品代碼頁時更新清單，帳號異動後 Excel 會提示重新掃描。設定頁標示尚未儲存的變更。
- **桌面重啟還原**：可還原已完成且成功保存的銷售報表；Excel 記住上次檔案與工作表並重新掃描，不還原之前的分析或寫入結果。報表還原提示包含保存時間，需重新查詢才能取得新資料。
- **快取可靠性修正**：Windows 先關閉無效報表檔再刪除；調整背景保存與快取關閉的併發追蹤，避免原先的等待競爭。

## 資料保存與隱私

桌面報表會非同步寫入 `%APPDATA%\RTA Excel Filler\sales-report.json.gz`，內含銷售結果、商品明細、帳號識別碼及保存時間。**gzip 只是壓縮，不是加密。** 同目錄的 `workbook-session.json` 會保存活頁簿路徑及工作表名稱。這些業務資料不受密碼的 Windows 認證管理員保護。

請勿分享上述檔案或包含它們的診斷資料。若只需移除還原資料，先關閉程式，再刪除這兩個檔案；若要徹底清除本機帳號與資料，依 [使用說明](../../README.zh-TW.md#帳號資料存在哪裡) 操作。網頁版的保存機制不同，不使用這兩個原生檔案。

重要結果仍應匯出。未完成的查詢、未儲存設定、Excel 分析／寫入結果，以及未成功寫入磁碟的報表，不保證重啟後保留。關閉時最多等待報表背景保存兩秒，不是持久保存保證。

## 更新方式（正式發布後）

- v0.4.9 可從「設定 → 檢查更新」取得正式版本，明確確認後才下載並重啟。
- v0.4.8 與更早的 API 客戶端需要一次手動切換至支援 Pages 的版本。請先完成並匯出工作、關閉程式、保留舊執行檔，再以相同路徑與檔名替換。
- 維持 Windows 10／11 64 位元免安裝版，預計附件為 `RTA-Excel-Filler-portable.exe` 與 `SHA256SUMS.txt`。正式公開前仍須驗證簽章、可信發行者、數值版本及校驗碼；未簽章 CI 草稿不可當作正式更新。

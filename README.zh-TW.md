# RTA 銷售分析

[English](README.md) | 繁體中文

**RTA 銷售分析**（英文名稱：**RTA Sales Analyzer**）是一套 Windows 桌面應用程式，用於檢視門店銷售、匯出 PDF 報告，以及將數字填入公司既有的 Excel 活頁簿。

安裝完成後，以滑鼠操作即可，無須撰寫程式或使用命令列。

本程式可：

1. **登入 RTA**，並自動處理驗證碼
2. **顯示各門店銷售**，並與上月及去年同期比較
3. **匯出 PDF 報告**（一份總報告，以及每間門店一份分店報告，便於會議使用）
4. **將當日銷售金額與交易次數**填入公司既有的 Excel 活頁簿

開始功能表與捷徑名稱為 **RTA 銷售分析**。  
安裝檔名稱仍為 `RTA-Excel-Filler-setup.exe`。此為沿用的舊檔名，安裝的即為本程式。

---

## 電腦需要什麼

- 64 位元的 **Windows 10 或 Windows 11**
- 可連線至 RTA 的網路
- 一組（或多組）具有所需門店權限的 **RTA 帳號密碼**

一般使用請安裝「安裝檔」。Windows 10／11 通常已隨 Microsoft Edge 提供 WebView2；少數缺少 Runtime 的電腦，安裝程式會協助下載。

## 怎麼安裝

1. 至 [Releases](https://github.com/Miku0139oao/rta-sales-client-go/releases) 下載最新版本。
2. 在壓縮檔或資料夾中找到 **`RTA-Excel-Filler-setup.exe`**，雙擊安裝。安裝檔以 Microsoft Trusted Signing 簽署。若 Windows 或 Edge 仍提示「不常下載」，選保留／仍要執行即可。
3. 安裝完成後，按鍵盤上的 **Windows 鍵**，搜尋 **RTA 銷售分析**，即可開啟。

同一時間僅能開啟一個視窗。若啟動後沒有反應，請先檢查工作列是否已在執行。

## 第一次使用：先加帳號

於左側選 **「帳號」**，再選右上角 **「新增帳號」**。

請填寫以下欄位：

- **顯示名稱**：供自己辨識的名稱，例如「主要帳號」、「北區」
- **帳號**：RTA 登入帳號
- **密碼**：RTA 登入密碼

建議按 **「測試並啟用」**。程式會實際登入 RTA，以確認帳號、密碼、驗證碼與門店權限皆可使用。  
未啟用的帳號不會用於「銷售分析」與「Excel 填入」。

![帳號頁](docs/images/account-pool-desktop-verified.png)

### 有多個帳號時

清單 **由上到下為優先順序**。  
同一間門店若有兩本帳號皆可存取，程式會使用較上方的帳號。

以每列右側的 **上移 / 下移** 調整順序。

密碼存放於 Windows 的「認證管理員」，不會以明文顯示於畫面或檔案中。  
刪除一筆帳號時，對應密碼一併刪除。

## 銷售分析

適用於檢視當月銷售、與去年比較，以及匯出 PDF。

1. 於左側選 **「銷售分析」**。
2. 選一本已啟用的帳號。
3. 勾選要檢視的門店（可全選）。
4. 分析期間請擇一：
   - **月份比較**（最常用）：選一個月份即可
   - **日期範圍**：自行指定起迄日
5. 按 **「開始分析」**，等待資料查詢完成。

![銷售分析概覽](docs/images/sales-analysis-overview.png)

### 月份比較的期間

選 8 月時，程式會一次查詢五段時間：

| 名稱 | 說明 |
| --- | --- |
| 本期 | 所選的月份 |
| 上期 | 上個月 |
| 前期 | 再上個月 |
| 去年同期 | 去年的同一個月份 |
| 去年下月 | 去年的下一個月（用於準備接下來要補貨或主推的商品） |

若所選月份尚未結束，前四段會計算至「與今天同一日」為止，以便公平比較。  
例如今天是 8 月 16 日，上期計算至 7 月 16 日，去年同期計算至去年 8 月 16 日。  
「去年下月」仍為完整一個月。

### 查詢完成後可檢視的頁面

- **概覽**：淨銷售、銷售金額、退款、交易次數、客單價、熱賣商品
- **每週變化**：本期內各週、各店的走勢
- **關注**：去年下月銷售較佳的商品，便於準備下個月
- **分類**：各分類在這幾期的差異
- **商品**：商品明細，可用上方分類或搜尋縮小範圍
- **門店比較**：各店本期、上期、去年同期

交易次數與客單價為「全店」數字。  
若已篩選某一個分類或某一個商品，這兩項會先隱藏，因為來源系統沒有該細項的全店數字。

### 匯出 PDF 與給 AI 的檔

畫面右上角按 **「匯出 PDF」**。若你剛勾了分類或搜尋，對話框預設 **依目前分析篩選**，並列出你勾的項目。

- **PDF 報告**與**匯出給 AI 分析**用同一組條件，不必再勾一次分類。
- 要整店數字時，改選 **不套用畫面篩選**。
- AI 檔是 Markdown，丟進任何 AI 就會出報告，不用再另外下指令。
- 有商品代碼群組時，總報告預設只放摘要；需要完整章節再選獨立詳細 PDF。

選一個資料夾後開始匯出。檔名重複會自動加數字，**不會覆蓋既有檔案**。完成後可按 **開啟資料夾**。  
逐步畫面請見 [使用教學](docs/tutorial.zh-TW.md)。

## 把數字填進 Excel

適用於公司每日填寫的活頁簿。  
程式只會寫入兩個欄位，而且 **一定另存新檔，原本的 Excel 不會被修改**。

公司檔預設工作表名稱為 `Dairly`（此拼法為原檔既有寫法，並非文件誤植）：

| 欄 | 內容 |
| --- | --- |
| C | 門店編號 |
| F | 日期 |
| L | 當天銷售金額（銷售減退貨） |
| AB | 當天交易次數 |

### 三個步驟

**1. 選擇範圍**

- 按 **「開啟 Excel 檔案」**，或將 `.xlsx` 放到視窗中（僅支援 `.xlsx`，不支援舊的 `.xls`）
- 選取工作表、開始日期、結束日期
- 核對「掃描摘要」：門市數、日期數、可用帳號是否合理
- 按 **「開始分析」**

![選擇 Excel 範圍](docs/images/excel-range-desktop.png)

**2. 檢查結果**

每一列會標示為：

- **將變更**：準備寫入新數字
- **不變**：與 RTA 一致，無須修改
- **問題 / 查詢失敗**：此列暫不寫入，請依說明處理或略過

![檢查 Excel 結果](docs/images/excel-results-desktop.png)

**3. 另存新檔**

預覽確認無誤後，按 **「另存並寫入」**，並指定新檔位置。  
完成畫面會分開顯示 **檔案名稱** 與 **位置**。  
按 **「開啟檔案」** 以 Excel 開啟，或按 **「在資料夾中顯示」**。

![寫入完成](docs/images/excel-success-desktop.png)

### 寫入前請注意

- **來源檔永遠不會被覆蓋。** 寫出的是另一個檔案。
- 儲存格內若已有不同數字，須先開啟 **「允許覆寫全部不同值」**，否則會列為問題列。
- 儲存格內若為 **公式**，程式不會修改，以免覆蓋公式。
- 查詢中途失敗時，可按 **「重試失敗項目」**。
- 若在登入完成前即取消，請重新按一次「開始分析」。
- 尚未查詢完成的結果不能存檔。
- 若要略過問題列、只寫入其他列：請等分析全部結束後，再開啟 **「略過全部問題列並寫入其他列」**，程式會再次確認。

C 欄若不是 RTA 門店編號，請到「設定」啟用本機對照檔（JSON 或 CSV）。請勿將含有真實門店編號的對照檔傳給他人。

## 設定

於左側選 **「設定」**。

| 項目 | 說明 |
| --- | --- |
| 主題、介面語言 | 可改為英文，或改為亮色／深色。**一經變更即生效**，無須再按儲存 |
| 每次最多查詢工作 | 預設 2000。一次選取過多天數與過多門店時，超過此上限即會停止 |
| 查詢工作並行數 | 預設 160，供單一帳號一次查詢多間門店。網路不穩或連線受阻時，可先降至 32 或 8 再試 |
| 本機對照設定 | 僅在 Excel 門店編號與 RTA 不一致時需要啟用 |

查詢工作或對照檔變更後，請按 **「儲存」**。

## 常見問題

**程式無法開啟，或視窗閃一下即關閉**  
Windows 10／11 通常已內建 Edge WebView2。若可攜版仍無法啟動，請改用 `RTA-Excel-Filler-setup.exe`；安裝程式會處理少數缺少 Runtime 的情況。

**同時開啟兩個視窗時，後者會立即關閉**  
此為預期行為，同時僅能執行一個執行個體。

**測試帳號失敗，持續提示驗證碼錯誤**  
請間隔一分鐘後再按一次「測試」。若仍失敗，請確認帳號與密碼，並確認此帳號目前可在瀏覽器登入 RTA。

**銷售分析顯示沒有門店**  
請到「帳號」確認此帳號已啟用，且最近一次「測試」成功。部分帳號本身沒有門店權限。

**Excel 許多列顯示「找不到門市對照」**  
C 欄編號與 RTA 門店編號不一致。請核對來源檔，或到設定指定對照檔。

**另存時提示來源檔已被修改**  
分析開始後，請勿再開啟 Excel 修改該來源檔。請重新掃描並再次分析。

**解除安裝後，下次重裝帳號仍在**  
此為設計行為：解除安裝不會刪除帳號。若要一併清除帳號，請先到程式的「帳號」頁刪除每一筆。

**密碼是否安全？**  
密碼交由 Windows 保管。銷售數字與 Excel 預覽僅保留於本次開啟的視窗中，不會另外存成明文檔。

## 帳號資料存在哪裡

帳號與加密後的登入狀態存放於下列資料夾（資料夾沿用舊名稱，以便既有資料仍可載入）：

`C:\Users\你的使用者名稱\AppData\Roaming\RTA Excel Filler`

一般無須自行修改此資料夾。若要徹底清除本機資料：請先在程式中刪除全部帳號，再刪除此資料夾。
